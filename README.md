## 📖 Overview

**Chemify** transforms abstract chemical formulas, stoichiometry calculations, and periodic properties into an intuitive, visually stunning interactive observatory. Built on a botanical field guide design aesthetic (earthy sage green `#4E5B47`, warm cream parchment `#FAF8F5`, and olive accents `#6F7F63`), Chemify bridges the gap between static textbook memorization and tangible laboratory understanding.

Whether you need to balance complex chemical reactions using linear algebra matrix null spaces, simulate copper redox single displacement on a digital heating plate, or study worked solutions with textbook-grade KaTeX typography — Chemify is engineered for students, researchers, and curious minds.

### 🔬 1. Interactive Periodic Table Observatory
* **Comprehensive 118 Elements:** Standard Mendeleev grid with IUPAC atomic masses, electronegativity, ionization energies, electron configurations, and discovery history.
* **Dynamic Bohr Shell Visualizer:** Animated quantum electron orbital orbits rendered in real-time SVG.
* **Multi-Filter Dimensionality:** Filter by chemical category (Alkali Metals, Noble Gases, Actinides, etc.), physical states at STP (Solid, Liquid, Gas), and radioactive isotopes.
* **Detailed Element Drilldown Modal:** Deep-dive modal covering physical properties, biological roles, cosmic abundances, and real-world industrial applications.

### 🧪 2. Chemical Reaction Studio & Interactive Lab Bench
* **Dual-Perspective Chemical Simulation:**
  * **🧪 Macroscopic Lab Bench Mode:** Realistic chemistry workstation with reagent bottles, gas wash flasks, solid jars, an Erlenmeyer reaction flask, magnetic heating plate, and live digital thermometer probe.
  * **🔬 Microscopic Molecular Field Mode:** 2D/3D CPK molecular geometry with single, double, and triple covalent bonds, kinetic particle collisions, thermal shockwaves, and sparks.
* **Strict Conservation of Mass & Stoichiometry:** Real-time atom conservation ledger ensuring input mass matches product mass ($m_{\text{reactants}} = m_{\text{products}}$).
* **Live Chemical Phase Transformations:** Liquid color evolutions (e.g. vibrant cobalt blue $\text{CuSO}_4$ fading to pale sea-green $\text{FeSO}_4$ while reddish-brown metallic copper precipitates), effervescent gas bubbles, and heating glow.
* **Reagent Stockroom Shelf:** 1-click addition of standard laboratory reagents ($\text{H}_2, \text{O}_2, \text{CH}_4, \text{N}_2, \text{HCl}, \text{NaOH}, \text{Fe}, \text{CuSO}_4, \text{H}_2\text{O}_2, \text{Al}, \text{Fe}_2\text{O}_3, \text{CaCO}_3$).

### 🧮 3. 10 Chemistry Calculators + Crash Course Field Guides
* **10 Specialized Solvers:** Instant calculation of molar masses, matrix reaction balancing, solution dilutions, gas laws ($PV=nRT$), Gibbs spontaneity ($\Delta G = \Delta H - T\Delta S$), and oxidation states.
* **KaTeX Display Typography:** Master equations and mathematical derivations rendered in textbook-grade LaTeX with automated left-to-right (`.formula-ltr`) mathematical isolation.
* **Worked Example Stepper:** Step-by-step problem solver with structured "Given Data" tags, targeted variables, formula derivations, and self-check interactive quizzes.
* **Category Drop-Side Hover Discovery:** Multi-level flyout menu and viewport-safe hover cards on category chips with 1-click solver / guide launch.

### 🌍 4. Trilingual Internationalization (i18n & RTL)
* Complete localization in **English (Default)**, **French (Français)**, and **Arabic (العربية)**.
* Native Right-to-Left (RTL) layout switching with bilingual math typography.

```
│   │   ├── explorer/

│   │   │   ├── LabView.tsx             # Reaction simulation studio coordinator

│   │       ├── ToolModal.tsx           # Dual-mode Solver & Crash Course modal

│   │       └── calculators/            # 10 modular chemistry calculators
│   ├── data/
│   │   ├── elementsData.ts             # 118 elements atomic data & electron shells
│   │   ├── reagentsData.ts             # Reagent catalog, states, hazard badges
│   │   └── crashCourse/                # Trilingual crash courses (en, fr, ar)
│   ├── i18n/
│   │   ├── LanguageContext.tsx         # React context for language & RTL state
│   │   └── translations/               # Common, elements, reactions, tools
│   └── utils/
│       ├── formulaParser.ts            # Recursive chemical formula & hydrate parser
│       ├── equationBalancer.ts         # Gaussian elimination linear algebra balancer
│       └── reactionEngine.ts           # Stoichiometric turnover & kinetic profile
```

### Chemical Mathematical Engines
1. **Gaussian Matrix Equation Balancer (`equationBalancer.ts`):** Constructs a compositional matrix where columns represent molecules and rows represent atomic species. Computes the kernel (null space) via integer row-reduction (RREF) to yield minimum integer stoichiometric coefficients.
2. **Recursive Formula Parser (`formulaParser.ts`):** Parses arbitrary chemical strings including multi-level brackets (`[Co(NH3)5Cl]Cl2`), hydrate dots (`CuSO4·5H2O`), and computes atomic mass fractions.
3. **KaTeX Rendering Safety (`MathEquation.tsx`):** Renders LaTeX with error-boundary recovery, isolated unicode bidi formatting, and responsive horizontal overflow handling.

## 🚀 Quickstart & Local Development

### Prerequisites
* **Node.js** $\ge 18.0.0$ (Node 20 or 22 recommended)
* **npm** $\ge 9.0.0$

### Installation
```bash
# 1. Clone repository
git clone https://github.com/solacode-SC/Chemify.git
cd Chemify

# 2. Install dependencies
npm install

# 3. Start local Vite development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
# Type check with tsc and bundle with Vite
npm run build

# Preview production build locally
npm run preview
```

## 🐳 Docker & Production Deployment

Chemify is fully containerized with a hardened multi-stage Docker build (`Node 22-alpine` builder + `Nginx-alpine` runtime) configured to listen on **ports 4326 and 5467** simultaneously:

```bash
# Build and run containers in detached mode
docker compose up -d --build

# Verify container health
curl -I http://localhost:4326/
curl -I http://localhost:5467/
curl -s http://localhost:4326/healthz
```

## 🛠️ Turnkey Makefile Automation (`chemify.solaymanbuilds.com`)

A dedicated [`Makefile`](file:///wsl.localhost/Ubuntu/home/soel/Desktop/Projects/Chemify/Makefile) provides turnkey orchestration for production containers, host Nginx reverse proxy, and SSL certificates:

| Target | Description |
| :--- | :--- |
| `make docker-build` | Build production Docker image (Node 22 + Nginx Alpine) |
| `make up` | Start production container on ports **4326** & **5467** |
| `make down` | Stop and remove running Chemify container |
| `make restart` | Gracefully restart Chemify container |
| `make logs` | Follow live container logs |
| `make status` | Check container health and probe ports 4326 / 5467 |
| `make deploy` | Complete Docker build & verify operational ports |
| `sudo make nginx-config` | Auto-configure host Nginx reverse proxy for `chemify.solaymanbuilds.com` |
| `sudo make ssl` | Issue and activate Let's Encrypt SSL certificate via Certbot |
| `make ssl-renew` | Test SSL certificate auto-renewal (dry-run) |
| `sudo make vps-setup` | Run complete end-to-end VPS deployment script |

## ⚡ Single-Command VPS Setup

Deploy Chemify on a fresh Ubuntu/Debian VPS with automated Docker, Host Nginx reverse proxy, and Let's Encrypt SSL in **one single command**:

```bash
# Inside the cloned repository on your VPS:
sudo make vps-setup
```

Or execute directly via `curl` on a fresh VPS terminal without cloning first:

```bash
curl -fsSL https://raw.githubusercontent.com/solacode-SC/Chemify/main/scripts/setup-vps.sh | sudo bash -s -- chemify.solaymanbuilds.com admin@solaymanbuilds.com
```
